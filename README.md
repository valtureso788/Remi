## 🎯 О проекте

**REMI** — это веб-приложение для мебельной компании, которое позволяет пользователям самостоятельно создавать и настраивать мебель в режиме реального времени с помощью интерактивной 3D-модели.

### Зачем это нужно?

| Проблема | Решение REMI |
|---|---|
| Клиент не может представить, как будет выглядеть мебель | 3D-визуализация в реальном времени |
| Сложно рассчитать стоимость с учётом всех параметров | Автоматический расчёт при каждом изменении |
| Долгий процесс согласования проекта | Мгновенная отправка проекта менеджеру |
| Нет возможности сохранить и вернуться к проекту | Локальное сохранение проектов |

## ✨ Возможности

### 🗂️ 1. Каталог мебели (8 типов)

Пользователь может выбрать один из 8 типов мебели, каждый с уникальными параметрами по умолчанию:

| Тип | Размер по умолчанию (Ш×В×Г) | Описание |
|-----|------|----------|
| 🗄️ Шкаф | 120×220×60 см | Вместительные шкафы для одежды |
| 🍳 Кухонный гарнитур | 240×85×60 см | Современные кухонные модули |
| 🛏️ Тумба | 60×50×40 см | Прикроватные и ТВ-тумбы |
| 🗃️ Комод | 100×90×45 см | Комоды с ящиками |
| 📚 Стеллаж | 80×200×35 см | Открытые стеллажи |
| 🖥️ Стол | 140×75×70 см | Рабочие и обеденные столы |
| 👔 Гардероб | 200×240×60 см | Гардеробные системы |
| 📖 Полка | 80×30×25 см | Настенные полки |

### 🎨 2. 3D-конструктор мебели

Полноценный конструктор с интерактивной 3D-моделью:

#### Настройка размеров
- **Ширина**: от 30 до 400 см (шаг 5 см)
- **Высота**: от 20 до 300 см (шаг 5 см)
- **Глубина**: от 15 до 100 см (шаг 5 см)

#### Настройка конструкции
- **Полки**: от 0 до 8 шт. (автоматическое равномерное распределение)
- **Секции**: от 1 до 6 (с вертикальными перегородками)
- **Ящики**: от 0 до 6 шт. (расположены внизу мебели)

#### Типы дверей
- Распашные (классические)
- Раздвижные (купе)
- Без дверей (открытый вариант)

#### Выбор материала (5 вариантов)
| Материал | Коэффициент цены | Визуальный эффект |
|----------|----------------:|-------------------|
| ЛДСП | ×1.0 | Матовая текстура |
| МДФ | ×1.2 | Гладкая поверхность |
| Дерево | ×1.5 | Натуральная текстура |
| Стекло | ×1.8 | Прозрачность + блеск |
| Металл | ×2.0 | Металлический блеск |

#### Цветовая палитра
- **8 цветов корпуса**: белый, чёрный, дуб, орех, венге, серый, бежевый, вишня
- **8 цветов фасадов**: белый, кремовый, антрацит, тёмно-синий, оливковый, бордовый, песочный, мятный

#### Фурнитура
- **Ручки**: современные (350₽), классические (500₽), минималистичные (250₽), скрытые (600₽)
- **Ножки**: без ножек, металлические (800₽), деревянные (600₽), пластиковые (300₽)

### 🖱️ 3. Работа с 3D-моделью

- **Вращение** — зажмите левую кнопку мыши и перемещайте
- **Масштабирование** — колёсико мыши
- **Перемещение** — зажмите правую кнопку мыши
- **Обзор со всех сторон** — свободная камера с ограничениями
- **Реальное время** — все изменения отображаются мгновенно

### 💰 4. Автоматический расчёт стоимости

Формула расчёта учитывает:

```
Итого = Базовая цена × Материал + Полки + Секции + Ящики + Двери + Ручки + Ножки
```

| Компонент | Формула |
|-----------|---------|
| Базовая цена | Объём (Ш×В×Г) × коэффициент типа мебели |
| Материал | Базовая цена × коэффициент материала |
| Полки | Количество × 450₽ |
| Секции | (Количество - 1) × 800₽ |
| Ящики | Количество × 1 200₽ |
| Двери распашные | 2 500₽ |
| Двери раздвижные | 4 500₽ |
| Ручки | Цена × количество секций |
| Ножки | Фиксированная цена |

### 💾 5. Сохранение и экспорт

- **Сохранить проект** — в localStorage браузера
- **Загрузить проект** — из списка сохранённых
- **Скачать PNG** — скриншот 3D-модели
- **Скачать PDF** — документ с полными параметрами заказа
- **QR-код** — генерация QR с конфигурацией проекта

### 📦 6. Оформление заказа

Форма заказа включает:
- Имя (обязательно)
- Телефон (обязательно)
- Email (опционально)
- Комментарий (опционально)

После отправки клиент получает уникальный номер заказа.

### ⚙️ 7. Админ-панель

Разделы админ-панели:
- **📦 Заявки** — таблица с заказами, статусами (Новая / В работе / Выполнен)
- **📊 Статистика** — заказы за день, выручка за месяц, средний чек, конверсия
- **📋 Каталог** — управление типами мебели и ценами
- **👥 Клиенты** — база клиентов с историей заказов

## 🚀 Установка и запуск

### Требования

- **Node.js** 18+ (рекомендуется 20+)
- **npm** 9+
- Современный браузер с поддержкой WebGL (Chrome, Firefox, Edge, Safari)

### Шаги

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/YOUR_USERNAME/Remi.git
cd Remi

# 2. Установите зависимости
npm install

# 3. Запустите dev-сервер
npm run dev

# 4. Откройте в браузере
# http://localhost:3000
```

### Сборка для продакшена

```bash
# Сборка
npm run build

# Предпросмотр
npm run preview
```

Собранные файлы будут в папке `dist/`.

## 🗄️ Каталог мебели

При выборе типа мебели из каталога автоматически загружаются соответствующие параметры по умолчанию и генерируется подходящая 3D-модель:

- **Шкафы, комоды, тумбы, стеллажи, гардеробы** → модель «Шкаф» (с корпусом, полками, секциями, дверями, ящиками)
- **Столы** → модель «Стол» (столешница + 4 ножки)
- **Полки** → модель «Полка» (доска + крепления)

## 🧊 3D-конструктор

### Технические детали рендеринга

- **Движок**: Three.js через React Three Fiber
- **Освещение**: ambient + 2 directional + 1 point (accent)
- **Тени**: ContactShadows для реалистичности
- **Окружение**: Studio preset (Environment от drei)
- **Камера**: PerspectiveCamera (FOV 45°)
- **Управление**: OrbitControls (вращение/зум/пан)
- **Параметрическая модель**: геометрия генерируется процедурно по параметрам

### Как работает модель

```
Каждое изменение параметра → React пересчитывает пропсы →
Three.js обновляет геометрию → Рендер нового кадра (60 FPS)
```
